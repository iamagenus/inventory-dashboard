# 📦 React Inventory Dashboard

A modern, responsive inventory management system built to track stock levels, calculate inventory value, and visualize data in real-time.

## 🚀 Live Demo
[https://inventory-dashboard-rosy.vercel.app]]

## ✨ Features
- **Dashboard Overview:** Real-time calculation of total inventory value and low-stock alerts.
- **Visual Analytics:** Dynamic bar charts visualizing stock by category (using Recharts).
- **Product Management:** Full Create, Read, Update, Delete (CRUD) functionality.
- **Image Support:** Add product thumbnails via URL.
- **Search & Filter:** Instant search by Product Name or SKU.
- **Data Persistence:** Uses LocalStorage to save data between sessions.
- **Export:** One-click CSV export for Excel integration.

## 🛠️ Tech Stack
- **Frontend:** React + Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Charts:** Recharts

## 🏃‍♂️ How to Run Locally
1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
